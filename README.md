# StoryNest for Android

Create picture books with your photos and words, arrange pages, and export PDFs to read or share.

## Download

- [Download StoryNest 1.1 APK](https://github.com/xcoffeetommyx/StoryNest-Releases/releases/download/v1.1/StoryNest-1.1.apk)
- [Latest release and notes](https://github.com/xcoffeetommyx/StoryNest-Releases/releases/latest)

Requires Android 8.0 or newer. Download the `.apk` under **Assets**, open it on your Android device,
and allow installation from your browser or file manager if Android asks. Updates use the same signing
key and preserve books from earlier release installations. Save an editable backup before uninstalling
or clearing app storage.

## Version 1.1

- Create pages from up to 50 pictures, with optional captions and order review.
- Save and restore editable book backups, including original pictures.
- Drag and pinch pictures in Crop; use center guides and clearer editor tools.
- Start with cover titles and page layouts, fit text, and review clipping before PDF export.
- Reach Undo, Redo, Add and Pages without hunting through a toolbar.

Each release includes `SHA256SUMS.txt` to verify the APK download. Development builds use a different
signing certificate and cannot be replaced directly by a release APK; preserve and verify editable
backups before changing installations.

This public repository hosts signed APK downloads and release notes. The application source is private.
GitHub's automatic source archives contain this repository's documentation, not an installable app.
